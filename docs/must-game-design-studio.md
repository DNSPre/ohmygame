# 澳门科技大学游戏设计工作台

本分支以 OhMyGame 为基础，参考目鱼 AI 的侧栏、对话创作区和快捷入口布局。
网页游戏项目使用游戏设计 Agent：支持策划讨论、制作首个可玩版本和预览验证。
默认使用 OhMyGame 可配置的模型提供商；目鱼 AI 是布局参考，没有接入其账号或 API。

本地运行：安装仓库要求的 Node.js 和 Bun，运行 `bun install --frozen-lockfile`，
然后运行 `bun run dev`。网页地址为 http://127.0.0.1:43220/，后端端口为 43210。
首次启动可连接一个模型，或跳过进入工作台。生成需要已连接的模型。
本分支默认将服务数据写入当前工作目录下的 `.data/`，不会自动读取原部署的项目或凭据。

如需将来单独构建 Mac 客户端，可运行 `bun run package:mac:dir`；本分支使用独立的
应用名称和包标识。原客户端和已交付的安装镜像无需替换。
